# Amber 浏览器扩展

Chrome / Edge / Firefox 扩展的独立发布仓。安装包见 Releases 中最新的 `browser-extension-v*`。

- Chrome / Edge：解压 ZIP，扩展页开启开发者模式，选择「加载已解压的扩展程序」
- Firefox 140+：`about:debugging` 临时载入，或使用 AMO 签名版
- 需要本机运行 Amber 0.6.4 或更新版本；扩展本身不下载视频
- 隐私政策：https://github.com/sumi856/Amber/blob/main/PRIVACY.md
- 支持：https://github.com/sumi856/Amber/blob/main/SUPPORT.md
